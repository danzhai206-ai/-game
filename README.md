# 数当てゲーム（Number Guessing Game）

## 概要
Pythonで作成した、ランダムに生成される数字を当てるコンソール型のゲームです。

ユーザーが数字を入力し、正解の数字を推測していきます。
難易度選択、試行回数制限、ゲームの再プレイ機能を実装しています。

## 使用技術
- Python
- randomモジュール

## 実装した機能

### 1. 数字のランダム生成
`random.randint()` を使用し、指定された範囲内で正解となる数字をランダムに生成します。

### 2. 難易度選択
ゲーム開始時に3段階の難易度を選択できます。

| 難易度 | 数字の範囲 |
|---|---|
| 1 | 1〜20 |
| 2 | 1〜100 |
| 3 | 1〜500 |

### 3. 数字の判定
入力された数字と正解の数字を比較し、以下のメッセージを表示します。

- 正解より小さい場合：「もっと大きい！」
- 正解より大きい場合：「もっと小さい！」
- 正解の場合：「正解です！」

### 4. 試行回数の制限
正解するまでの試行回数をカウントします。

5回以内に正解できなかった場合はゲーム失敗となります。

### 5. リプレイ機能
ゲーム終了後に再プレイするかどうかを選択できます。

再プレイを選択すると、新しい正解の数字が生成され、試行回数もリセットされます。

## 実行方法
